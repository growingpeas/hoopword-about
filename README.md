# Hoopword

**Merge your embroidery alphabet's letter files into one .pes name, on your phone.**

An embroidery alphabet font comes as one file per letter (A.pes, B.pes, C.pes…), and putting the letters of a name together usually needs a computer program. Hoopword merges the letter files into a single .pes file for your machine, right on your phone.

## What it does

- Pick the folder that holds your letter files; each letter is found from the file names (A.pes, font_A.pes, A_upper.pes, "upper" and "lower" folders)
- Type a name and see the stitches as the machine will sew them
- Letters sit on one baseline; g, j, p, q and y hang below it
- Adjust the letter spacing in millimetres, and check the size against a 4×4, 5×7 or 6×10 inch hoop
- Each letter keeps its own thread colours, with a trim and a jump between letters
- Save the .pes or share it to your machine's app, email or cloud storage
- A sample alphabet is included, to try it before you buy a font

Reads .pes (all versions) and .dst letter files. Writes .pes version 1.

## Privacy

Your letter files are read only from the folder you pick, on your phone. Nothing is uploaded, and Hoopword asks for no storage permission.

Sew a test on scrap fabric before your final piece, and use only letter files you hold a license for. Works with .pes files for Brother and Baby Lock embroidery machines, and with letter files sold on Etsy or made in PE-Design or Embrilliance.
